# Void Pointer with a Function

## Author
M.Likitha

## Description
This program demonstrates passing different data types
to the same function using a void pointer.

The function identifies the data type using a character
and performs the appropriate type casting before
dereferencing the pointer.

## Concepts Used
- Void pointer
- Functions
- Function arguments
- Type casting
- Dereferencing
- Multiple data types

## How to Run

gcc void_pointer_function.c -o void_pointer_function

./void_pointer_function

## Sample Output

Integer: 50
Float: 87.50
Character: A
